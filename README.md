# The Living Stack

**A field guide from civilizational diagnosis to adaptive architecture.**

[Read the launch message](https://guten.ink/livingstack/)

*The Path of Many Arrows* asks why we need better civilizational design. *The Living Stack* asks how we might begin building it without losing the humans it is meant to serve.

The book connects three lines of work:

- *The Path of Many Arrows* provides the literary journey and civilizational diagnosis;
- Tiers develops a technical grammar for adaptive architecture;
- NEURO explores a civilizational physiology, with Neusphere as a distributed cognitive commons.

Its guiding question is: **What kind of stack is worthy of intelligence?**

## Repository purpose

This repository is intended to support development and publication of the book. It may contain:

- publication-ready Markdown or Quarto source files;
- book structure and rendering configuration;
- diagrams, references, and approved media;
- conversion and publication tooling;
- selected web and ebook outputs where appropriate.

The author's working manuscript remains authoritative unless explicitly designated otherwise. Derived publication files should preserve a clear path back to their source.

## Approach

The book is a field guide rather than a final blueprint. It considers how to make assumptions visible, model consequences, support viable transitions, preserve human agency, and keep institutions and technologies open to correction.
